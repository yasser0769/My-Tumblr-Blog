# مدونة ياسر الشهري — ثيم Tumblr

أعيد تصميم `Tumblr.html` وفق الثيم المرفق: خلفية ورقية بلون `#f7f4ec`، توهّج كهرماني وأزرق، خطوط ثمانية، عمود قراءة بعرض 620px، وفواصل نجميّة بين التدوينات. خطوط المرجع السبعة والصور الزخرفية محفوظة في `assets`، ويحمّلها القالب عبر روابط HTTPS مباشرة. لا تحتاج إلى رفع ملفات منفصلة إلى Tumblr. تستخدم الخطوط نسخة المستودع على فرع `v2`؛ أبقِ هذا الفرع متاحًا.

## التركيب

1. احفظ نسخة من HTML الحالي في Tumblr.
2. افتح تخصيص المظهر ← تحرير HTML، ثم انسخ محتوى `Tumblr.html` كاملًا والصقه مكان القالب الحالي.
3. راجع المعاينة ثم احفظ.
4. يمكن تعديل `Hero Location` و`Hero Tagline` وإظهار المقدمة عبر `Show Hero` من إعدادات المظهر. يأخذ عنوان المقدمة اسم المدونة من Tumblr.

تظهر روابط «اسألني» و«أرسل» عند تفعيل Ask وSubmissions من إعدادات Tumblr. يستخدم «الأرشيف» و«عشوائي» صفحات Tumblr الأصلية. رابط «من أنا» هو `/WhoAmI`، كما في القالب السابق؛ احتفظ بالصفحة بهذا الرابط. صفحات المدونة الإضافية متاحة من «المزيد» وعلى قائمة الجوال.

## المعاينة المحلية

```sh
python3 tools/build-preview.py
python3 -m http.server 8765 --bind 127.0.0.1
```

افتح http://127.0.0.1:8765/preview/index.html. يمكنك أيضًا فتح `preview/index.html` مباشرة في المتصفح.

المعاينة تُنشأ من القالب الفعلي، مع نصوص وصور مأخوذة من الملف المرجعي. تحتوي الرئيسية والتدوينة وصفحة «من أنا» والتنقل بين الصفحات. الإعجاب وإعادة التدوين والنماذج هنا أمثلة محلية؛ تشغيلها الحقيقي يعتمد على Tumblr. لا تُرفع ملفات `preview` إلى Tumblr.

## التحقق

```sh
node --test tests/*.test.js
```

اجتازت اختبارات المشروع الـ22. روجعت الواجهة في المتصفح بعروض 320 و390 و768 و1280 بكسل، مع مراجعة صفحة التدوينة و«من أنا» وفتح قائمة الجوال والمشاركة وإغلاقهما بمفتاح Escape. احتُفظ بمنطق عرض الصور والفيديو والنص البديل ومشغّل الصوت الموجود في القالب.

القالب منشور في مستودع GitHub على فرع `v2`، ولم يُثبت على Tumblr من خلال هذا المشروع. توجد نسخة القالب قبل إعادة التصميم في `.workbuddy-ai/backups/Tumblr-before-paper-2026-10-06.html`.

## توافق حفظ Tumblr

لا يحتوي ملف القالب على موارد `data:` أو نصوص `http://`. تستخدم الخطوط GitHub Raw عبر HTTPS والصور الزخرفية jsDelivr عبر HTTPS. عند تحديث القالب، انسخ النسخة الأحدث كاملة إلى محرر Tumblr.
